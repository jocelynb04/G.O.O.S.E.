# AMP-H570 conceptual Eco Caravan EX Amphibian

[Assumptions and sources](AMP_H570_ASSUMPTIONS_AND_SOURCES.md) | [Current verification](AMP_H570_VERIFICATION.txt)

Run `eco = run_eco_caravan;` for the 150-KTAS mission at 10,000 ft and the separate 164-KTAS continuous-power check.

This separate MATLAB project replaces the prior PT6-plus-motor concept with an AMP-H570-inspired parallel hybrid powerplant. It retains the EX amphibian airframe and float weight/drag. It is a conceptual amphibian variant, not a validated reproduction of Ampaire's actual Eco Caravan landplane, a physical installation design or an approved conversion.

## Run in MATLAB Desktop

Extract the ZIP. Restart MATLAB if another version of this project has been loaded; select this extracted folder as Current Folder. Enter:

```matlab
addpath(pwd,'-begin')
eco = run_eco_caravan;      % replacement powerplant, mission table and plots
verify_eco_project         % syntax checks, all regression tests, saved report/plot
```

Only MATLAB is required. Tested in R2025a Update 1. No Aerospace Toolbox or external course code is needed. Results are in `eco` (singular). Read `eco.feasible` before interpreting totals: on failure, `eco.failure` and `eco.failure_segment` explain the stop, and totals reflect only completed time steps.

Inspect `eco.segments`, `eco.trace`, `eco.fuel_used_lb`, `eco.final_soc`, `eco.mtow_margin_lb`, `eco.battery_recharged_kWh` and `eco.mass_balance_error_lb`. Use `struct2table(eco.segments)` for a readable table. `run_eco_caravan([],false)` suppresses plots. `AMP_H570_results.mat`, `AMP_H570_mission.png` and `AMP_H570_VERIFICATION.txt` are generated by verification.

The existing `run_caravan` and `run_hybrid_caravan` commands remain archived conventional and PT6-retained hybrid examples. They do NOT select the AMP-H570. Similarly, the inherited sizing loop and constraint envelope still describe their original conventional model. Use the new `run_eco_caravan` / `eco_mission` entrypoints for this powerplant. None of the twelve original adapted model files has been modified for this extension.

## Published inputs versus assumptions

`AMP_H570_SPEC_PROVENANCE.json` records origins. Manufacturer data used:

| Input | Published value | Source |
|---|---:|---|
| Combined takeoff/peak shaft power | 764 shp (570 kW rounded) | supplied PDF pp. 2–3 and manufacturer webpage |
| Combined max-continuous rating | 543 shp (405 kW rounded) | manufacturer AMP-H570 webpage |
| Cruise BSFC without electric boost | 0.34 lb/(hp hr) | supplied PDF p. 3 |
| Net boost BSFC, recorded only | 0.32 lb/(hp hr) | supplied PDF p. 3 |
| Dry mass bound | less than 1000 lb | supplied PDF p. 3 |
| Powerplant height / width / length | 29.5 / 33.5 / 51 inches | supplied PDF p. 3 |

The SHP ratings govern calculations; their paired kW values are rounded in the sources. The 0.34 value is applied to combustion shaft work, including generation. The 0.32 net figure is not multiplied onto an already reduced combustion share: that would double-count a hybrid efficiency benefit. No advertised percentage fuel saving or range target is hardcoded.

Source URLs: supplied document at https://fd46bca4-8fdb-4a60-bb5a-984ecb406747.filesusr.com/ugd/1fdb50_1426d830e26d49dbb6397c657b0c0d62.pdf ; manufacturer engine page https://www.ampaire.com/amp-h570 ; manufacturer vehicle page https://www.ampaire.com/vehicles/eco-caravan . The supplied PDF is bundled unchanged under `sources/`.

The public information does not provide a complete component operating map. The following remain user-editable assumptions, NOT manufacturer specifications:

- Core maximum 543 hp and motor maximum 221 hp, allocating the continuous/peak system ratings. That difference is not a verified motor continuous rating or an independent certified engine rating.
- Maximum 120-second continuous burst above the 543-hp combined continuous rating. This enforces a finite boost interval but is not a published takeoff duration. The timer resets below the continuous threshold; heat accumulation/cooldown is not modeled.
- 950-lb dry assembly, selected below the published mass bound, including the combustion engine, electric machine and core power electronics. Exact installed mass and whether Ampaire's dry-mass definition includes any battery equipment are unspecified.
- External 40-kWh pack at 250 Wh/kg, 100% initial SOC, 20% minimum SOC, 6-C maximum discharge, 1-C maximum charging, and 30-kg installation allowance. These are assumed technology values and installation scope.
- Motor/generator efficiency 0.95, inverter 0.97, gearbox 0.98, battery charging efficiency 0.95; 2-kW hotel load. Motor rating is also used as the reversible-generator shaft limit.
- 30-kW charging request, 90% charge target SOC. Charging automatically reduces to available engine headroom and battery room, paying for its shaft work with fuel.
- Flat core rating to 10000 ft; above that altitude, a sigma-ratio exponent of 0.65. This replaces the old PT6 lapse in the new dispatch only, and is an assumed turbocharged behavior, not a hot/high performance guarantee.
- Existing constant propeller efficiencies are retained. No new engine fuel map, low-load/idle behavior, temperature limit, RPM/torque curve, or extra external installation drag has been identified. The idle fuel floor remains zero and is optimistic at low power.

## Replacement weight accounting

The previous example ADDED a motor/pack to the retained PT6. This example subtracts the baseline PT6 installed-engine allowance before adding the replacement assembly:

```
reference amphibian empty weight       = 5975 lb (existing calibrated anchor)
removed installed PT6 allowance        = 425*1.4 = 595 lb (existing assumption)
new powerplant assembly dry mass       = 950 lb (assumed)
external battery pack                  = 40*1000/250 kg = 352.7 lb
additional installation allowance      = 30 kg = 66.1 lb
modeled replacement empty weight       = 6748.9 lb
net change from reference              = +773.9 lb
```

The integrated electric machine is included in the 950-lb assembly and is not added a second time. `eco.motor_mass_lb` is NaN because a separate measured motor mass is unavailable. Neither battery discharge nor recharge changes the modeled battery mass. The 595-lb removal is a modeling allowance, not a weighed PT6 installation. The original 2162.7-lb unallocated empty-weight calibration residual remains, as do the existing float assumptions.

Dimensions are recorded for installation screening, not used to assert clearance or a new cowling shape. The retained exterior wetted-area model cannot infer cooling inlets, pod drag, engine mounts or CG from engine-envelope dimensions alone.

## Mission and switching

Active inputs: `AMP_H570_requirements.json`. Segment modes:

- `fuel`: combustion engine supplies propeller power; battery supplies hotel loads.
- `electric`: engine ideally off/declutched; motor supplies propeller power and battery supplies hotel loads.
- `hybrid`: requested propeller shaft power is split using `electric_fraction`.
- `charge`: combustion engine supplies propeller plus generator shaft power; generation supplies hotel loads and then charges the battery within configured limits. Motor propulsion and generation are not simultaneous.

All transitions are instantaneous idealizations at segment boundaries. No automatic fallback between propulsion modes occurs. The charging mode's reduction of charge rate is explicit load management, not a source switch. Charge gained during cruise is recorded as a negative segment `battery_kWh`. Total net battery use equals discharged energy minus recharged energy.

The ten-segment example keeps electric taxi, a two-minute assisted takeoff, combustion climb, 500-nmi cruise at 150 KTAS/10000 ft with recharging, descent, reserve climb, 45-minute loiter, descent to 500 ft, electric final approach and a landing-run placeholder. Climb remains 600 fpm. Final approach is 3 degrees downward from 500 ft at 85 KTAS using takeoff-flap/gear-up drag/lift coefficients as a PARTIAL-FLAP APPROACH PROXY. It does not establish an approved flap/speed schedule. The cruise distance is 500 nmi; climb, descent and loiter also involve horizontal travel, so no maximum-range claim is made.

Two changes from the older generic hybrid mission are explicit:

1. Takeoff shaft demand is reduced from 867 to 764 hp to respect the replacement combined rating. The model does not prove that the same water takeoff distance is retained.
2. Full landing-flap electric approach at 85 KTAS fails the modeled motor limit. The default uses a partial-flap aerodynamic proxy; a fuel-powered full-flap option is provided instead if that aerodynamic tradeoff is undesirable.

Run the alternative and intentionally infeasible profiles:

```matlab
fuel_approach = run_eco_caravan('AMP_H570_fuel_approach.json');
old_takeoff = run_eco_caravan('AMP_H570_original_867hp_demand.json');
full_flap_electric = run_eco_caravan('AMP_H570_85kt_approach.json');
```

The last two are EXPECTED to return `feasible=false`, at takeoff peak power and electric approach motor power, respectively. Their partial totals are not complete mission predictions. A larger battery alone cannot cure a motor or combined shaft-power shortfall.

## Tested illustrative results

At 800-lb payload (including crew) and 1450-lb loaded fuel: takeoff weight about 8998.9 lb, 63.1 lb below the inherited 9062-lb MTOW; mission fuel about 724.6 lb; battery discharged 12.75 kWh, recharged 4.14 kWh, net draw 8.62 kWh; final SOC about 78.5%. These depend on the optimistic/uncertain assumptions above. They are not Ampaire flight-test results. Do not directly compare the fuel total with the earlier conventional model's 1550-lb result: loading, ground fuel accounting, climb path, powerplant, final-approach configuration and charging differ.

The combustion BSFC change supplies much of the fuel reduction relative to the prior PT6 model; electric energy is not free, and all modeled charging shaft work consumes fuel. No conventional-vs-hybrid maximum-range, matched-weight or matched-reserve optimization is claimed by this demonstration.

## Mathematical checks and limits

`eco_mission` reuses the previously tested time-step flight integration: lift/drag and vertical work determine required propeller shaft power; fuel consumption reduces aircraft weight, battery energy use does not. `AMPH570Powertrain` enforces source, combined shaft, peak-time, charge/discharge and SOC limits. It records engine output used for generation separately from net propeller demand.

With engine-driven charging, generator DC output is limited by (engine available shaft power minus propeller demand), reversible-machine rating, efficiencies, charge-rate request and available battery headroom. Hotel demand is subtracted first. Chemical energy stored equals DC power entering the pack times charging efficiency and elapsed hours. Fuel is BSFC times the ENTIRE engine shaft output (propulsion plus generator work). Charging cannot create energy or bypass the combustion power limit.

The trace includes combustion shaft hp (including generator work), electric propulsion kW, generator shaft kW, and signed battery chemical-energy kW. Failures leave the source state unchanged for that failed step; mission trace totals include committed steps only. Unit tests check shaft allocation, no 867-hp operation, peak timing, transactional failures, fuel consumption, recharge energy/fuel, SOC target, rate/engine headroom, altitude assumptions, mission conservation, alternative approach feasibility and integration refinement.

Floats remain represented by the inherited 665-lb net configuration proxy and 0.012 float-drag increment. No float hydrodynamics, battery-pod/float interference, waterproofing, buoyancy, propeller clearance, cooling installation, CG, structural design or certified water takeoff/landing model is available. The actual Eco Caravan is described by Ampaire as a 208B/EX retrofit with a cargo-pod battery; that geometry and its compatibility with floats are not established here. The original calibrated empty-weight and generic aerodynamic assumptions also remain.

Dual-bank combustion fault tolerance, engine-out/electric-out failures, restart energy and switch dynamics are not simulated. No fault-tolerance or go-around guarantee follows from the normal-operation energy calculation. The battery reserve and 45-minute loiter are modeling choices, not a legal reserve determination. Manufacturer marketing range/fuel targets are not calibration constraints.
