# Conventional Caravan EX Amphibian constraint analysis

Open this folder in MATLAB. Run `result = run_profile;` for the mission or `analysis = run_constraint_analysis;` for the matching chart. `run_caravan` runs the mission and combined sizing constraints. The inputs are in `config/`, the runtime is in `src/`, and the chart runner recreates PNG, PDF, FIG, CSV, and MAT files in `outputs/`.

See [constraint assumptions](docs/CONSTRAINT_ANALYSIS.md) for the climb, cruise and water-landing models. The chart is an engineering screen.
