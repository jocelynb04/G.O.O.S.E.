# Active analysis inputs

| File | Role |
|---|---|
| `Ttpa_requirements_Concept2.json` | RFP targets, geometry, aerodynamics, component weights, missions and source configuration |
| `concept2_study_inputs.json` | Operating schedules, electrical assumptions, failures and sizing-search settings |
| `turbine_engine_catalog.json` | Fixed turbine specifications and performance anchors; stays beside requirements for relative catalog lookup |
| `study_input_register.csv` | Provenance and validation needs for study assumptions |

The historical IHW3 input is in `Supplemental/Legacy/Inputs` and is not the active hybrid input. All paths above are relative to this folder. Changes do not update saved results automatically.
