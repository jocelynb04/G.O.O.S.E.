Team 4 Repository

Purpose: 
The purpose of this repository is to store the code built for Team 4, "Ground and Oceanic Overwing Shuttle Express - G.O.O.S.E." All code developed by team members will be uploaded to this repository and kept up-to-date as developments are made. 

Structure:
The repository is organized so any and all code developed is stored in the "code" folder. Within the "code" folder, subfolders for each assignment will be added to ease the accessibility of our code for grading of assignments. Code developed outside of the context of assignments will be stored in separate folders within "code". The "code" folder includes assignment subfolders such as THW3 and THW5, containing code related to Team Homework 3 and Team Homework 5. The code for out preliminary model exists within the THW3 folder, and any code used to perform trade studies exists within the "Trade Studies" folder.
